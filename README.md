# dsh-erii-pet · 绘梨衣桌宠

把《龙族》里的**上杉绘梨衣**放到 DeepSeek Harness 的页面上、以及 Windows 桌面上。

![绘梨衣桌宠](docs/preview.png)

- 红发、红白巫女风，头顶一只小黄鸭；会呼吸、眨眼、走路、挥手、害羞、打盹。
- 点她会回应、要摸头；右键可以喂冰淇淋、和她说话、让她睡一会儿。
- 会自己小声碎碎念，会记得刚才聊过什么。
- 语音由 Edge TTS 在本机合成（首次需要联网），按句缓存，复播不再请求。
- 页内与桌面两种形态共用同一份渲染代码；桌面是透明、置顶、可拖走的小窗。

## 安装

这是一个 DSH 插件包，目录本身就是包根目录：

1. 克隆仓库：`git clone https://github.com/sensencjq/dsh-erii-pet.git`
2. 打开 DSH 的 **插件管理 → 添加插件**，选择该目录。
3. 启用后刷新页面，她出现在右下角。

桌面形态用的是本机已有的 Electron（由 DSH 提供），不需要额外安装环境。
语音走 Edge 的公开 TTS 接口，第一次说话需要联网，之后读本地缓存。

## 用法

| 操作 | 效果 |
| --- | --- |
| 左键点她 | 挥手回应 + 说一句（点击台词） |
| 拖拽 | 拎起来，松手会落回屏幕底部（页内） |
| 右键 | 菜单：摸头、冰淇淋、聊天、睡觉、声音开关、桌面模式、设定、躲起来 |
| 聊天窗 | 直接对她说话；回复走当前会话的模型，并记住最近几轮 |

设定面板里能调声音大小、音色、怎么称呼你、她的个子，以及是否同时在桌面显示。

## 数据与配置

- 配置：`$DSH_HOME/erii-pet/config.json`
- 聊天记忆：`$DSH_HOME/erii-pet/memory.json`
- 语音缓存：`$DSH_HOME/erii-pet/voice-cache/`
- 人设与台词：`data/lines.json`（改完重启插件生效）
- 动画图集：`assets/spritesheet.webp`（8 列 × 11 行、单帧 192×208）

这些都是本机运行时数据，不进仓库；`data/lines.json` 里的人设与台词才是仓库里可改的部分。

## 从源码构建

`client.js` 与 `helper/renderer.js` 是构建产物——由 `src/pet-core.js`、两个模板和立绘内联生成：

```bash
node scripts/build.mjs
```

改 `src/` 或换立绘之后都要跑一次，否则页面加载的还是旧产物。

## 目录

```
assets/            图标与动画图集
art/ art-v3/       立绘来源（3D 渲染图、矢量图与生成脚本）
data/              人设、台词、角色考据
docs/              详设与预览图
helper/            桌面形态的 Electron 窗（main / preload / renderer）
locale/            插件元数据的中英文案
scripts/build.mjs  构建脚本
src/               渲染核心、模板与宿主端（路由、TTS、记忆、桌面窗）
```
