# 绘梨衣桌宠

把《龙族》里的上杉绘梨衣放到 DeepSeek Harness 的页面上，以及 Windows 桌面上。

## 她是谁

红发、红白巫女服、深玫瑰红色的眼睛，头顶有一只小黄鸭。安静，几乎不主动开口；说话很短，常用逗号或省略号断开，一句只有几个字。喜欢冰淇淋、甜食、海棠花和摩天轮，喜欢被摸头，怕一个人待着。

这个插件把她做成了会动的桌宠：她会在你的屏幕角落呼吸、眨眼、偶尔走两步；你点她，她会挥手回应；你右键和她说话，她会用她那种很轻、很短的方式回答你。

## 能做什么

- **页内形态**：挂在 DSH 页面右下角；整层鼠标穿透，只有她本人与面板接鼠标。
- **桌面形态**：透明、无边框、置顶、不占任务栏的小窗，可以拖到屏幕任意位置，位置会被记住。
- **动画**：从社区绘梨衣宠物包的 8×11 动画图集里取帧播放——待机呼吸、行走、挥手、害羞、打盹都是逐帧动画，不是静态图加滤镜。
- **互动**：摸头、喂冰淇淋、聊天、睡觉 / 叫醒、声音开关、躲起来。
- **自言自语**：每隔几分钟小声说一句；关掉就不再打扰。
- **语音**：用 Edge TTS 在本机合成，按句缓存；可换音色、调音量、调语速与音调（默认比标准音色更慢、更轻，贴近她「声音清澈、很小声」的设定）。
- **聊天**：走当前会话的模型，带着她的人设与最近几轮记忆；模型不可用时她会用固定台词回应，不会报错弹窗。

## 怎么用

安装后刷新页面，她出现在右下角。

- 左键点她：挥手 + 说一句。
- 拖拽：页内会跟着鼠标走，松手落回底部；桌面窗则是整窗跟着走。
- 右键：打开菜单，可以摸头、喂冰淇淋、聊天、让她睡觉、切换声音、切到桌面、打开设定。
- 设定：音量、音色、称呼、个头、是否自言自语、是否同时在桌面显示。

## 数据与配置

都在 `$DSH_HOME/erii-pet/` 下：

- `config.json`：显示方式、音色、音量、尺寸、称呼、位置等。
- `memory.json`：聊天记忆（最近 200 条，按轮数截取进上下文）。
- `voice-cache/`：合成过的 mp3，按句子与参数哈希命名。
- 人设与台词在插件包的 `data/lines.json`；动画图集在 `assets/spritesheet.webp`；改完重启插件生效。

## 素材与限制

- 绘梨衣是江南《龙族》的角色，本插件是非商业同人作品；角色版权归原作者所有。
- 动态立绘素材来自 Petdex / Codex Pets 社区的「绘梨衣」宠物包（作者 ZP D.），仅作个人本地使用，不随仓库再分发；素材版权归原作者，作者如要求可移除。
- 语音是机器合成，不是动画或游戏原声；音色来自微软 Edge 的公开 TTS 服务，首次合成需要联网。
- 桌面模式依赖本机 Electron（DSH 桌面版共享的那一份）；找不到时页内形态照常工作。
- 聊天会消耗当前会话模型的额度；只互动、不聊天时只有语音合成会联网。
